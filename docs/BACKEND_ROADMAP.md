# نقشه راه فنی توسعه بک‌اند پلتفرم دیجیتال نتا (Neta.land)

این سند مرجع رسمی، گام‌به‌گام و تاییدشده برای اتصال فرانت‌اند نتا‌لند به پایگاه داده، سیستم احراز هویت، کیف‌پول و درگاه‌های سرویس است.
